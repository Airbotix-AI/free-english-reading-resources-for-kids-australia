# Contributing

Submit a public official source, the exact free scope, account/device/location conditions, a review date and a proposed age/year use case. Explain the learning purpose and distinguish adult teaching resources from independent child activities. Keep every repository file in Markdown. Do not add workflows, copied books, personal data, affiliate links or unsupported curriculum claims. Maintain all three language editions and their cross-links. A resource can be free to access without being open-licensed.
